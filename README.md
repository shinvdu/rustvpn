# GoVPN Rust rewrite

This directory is the beginning of a wire-compatible GoVPN 5.7 rewrite in
Rust.  The original Go tree is intentionally untouched.

## Status

Implemented and differentially tested against the Go implementation:

- `govpn-crypto`
  - XTEA-as-PRP (Go byte order)
  - Salsa20 / XSalsa20 / HSalsa20
  - Poly1305
  - BLAKE2b-256
  - Chaffing-and-Winnowing with the specialised one-byte Poly1305 formula
  - SAEP/OAEP-style AONT
  - encless mode (CnW over AONT)
  - Argon2d v1.3 + Ed25519 verifier derivation (Go verifier strings)
- `govpn-proto`
  - classic, noise and encless transport packet encode/decode
  - 257-bit sliding anti-replay window
  - TCP exact-serial mode
  - the full PAKE handshake (DH A-EKE), including the exact extra25519
    representative encoding, Ed25519 signatures, IDtag and all four
    message layouts
- `govpn-verifier`
  - CLI-compatible verifier generator/validator (`-key`, `-verifier`, `-m`,
    `-t`, `-p`, `-warranty`; `-egd` is not implemented yet)

Not implemented yet (next milestones):

- UDP/TCP networking, HTTP proxy, TAP devices, configuration, stats
- CPR, heartbeat scheduling, rekey lifecycle, scripts
- packaging and CLI-compatible client/server binaries

## Tests

```bash
cd rust
cargo test
```

The tests consume `testdata/go_vectors.json`, generated by the real Go
implementation.  They verify:

- every primitive byte-for-byte
- classic/noise transport packets byte-for-byte in both directions
- encless packets decode correctly
- all four handshake messages byte-for-byte in plain/noise/encless modes,
  including the resulting master key, with a deterministic RNG stream that
  matches the Go oracle
- verifier seed/public key and forms match Go
- TCP/UDP replay behaviour and roundtrips

The handshake and Elligator/`extra25519` vectors are part of the
differential tests as well.

## Regenerating the Go oracle vectors

From the repository root (the Go source is only *read*, never modified):

```bash
GO111MODULE=off GOPATH=$(pwd) go run rust/tools/gen-vectors/main.go \
    > rust/testdata/go_vectors.json
```

The generator derives deterministic handshakes by replacing `govpn.Rand`
with a SHA-256 based stream and reads the exported `Peer.Key` to capture
transport packets.

## Verifier interoperability

```bash
# Rust validates a Go-generated verifier:
rust/target/debug/govpn-verifier -verifier "$LONG_FORM" -key pass.txt

# Go validates a Rust-generated verifier:
./govpn-verifier -verifier "$(rust/target/debug/govpn-verifier \
    -key pass.txt -m 1024 -t 4 -p 1 | head -1)" -key pass.txt
```

Both directions currently print `true`.
